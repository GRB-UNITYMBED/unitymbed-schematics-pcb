# UnityMbed Hardware Design Assets

Official open-source hardware design assets, circuit schematics, and multi-layer PCB production files for the **UnityMbed Starter (Nano)** and **UnityMbed Pro (UNO)** development boards.

## 📂 Repository Structure

The hardware design assets are organized as follows:

* **hardware-design/**
    * `Schematic_Nano.pdf`: Complete circuit schematic for the UnityMbed Starter board.
    * `PCB_Nano.pdf`: Multi-layer PCB layout and copper layer production files for the Starter board.
    * `Schematic_UNO.pdf`: Complete circuit schematic for the UnityMbed Pro board.
    * `PCB_UNO.pdf`: Multi-layer PCB layout and copper layer production files for the Pro board.

## 🛠️ Hardware Specifications Overview

* **Main Processor:** Nations N32G031 32-bit Arm Cortex-M0+ running at 48 MHz.
* **Advanced Analog Front-End:** Integrated 12-bit 1Msps ADC, built-in OPAMP, Comparator, and Programmable Gain Amplifier (PGA up to 32x).
* **Applications:** Engineered for real-time control, direct sensor acquisition, and industrial IoT applications.
