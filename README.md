# UnityMbed Hardware Design Assets

Official open-source hardware design assets, circuit schematics, and multi-layer PCB production files for the **UnityMbed Starter** and **UnityMbed Pro** development boards.

## 📂 Repository Structure

The hardware design assets are organized as follows:

* **hardware-design/**
    * `Schematic_Starter.pdf`: Complete circuit schematic for the UnityMbed Starter board.
    * `Schematic_Pro.pdf`: Complete circuit schematic for the UnityMbed Pro board.
